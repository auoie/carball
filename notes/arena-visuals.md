# Arena visuals: Stadium_P ("DFH Stadium"), spec (static session, 2026-10-08)

Live build (2026-10-06). Game frame: uu, z up; team 0 blue defends −Y, team 1 orange defends +Y. Tags: [A]
package/archetype data; [S] script; [N] native (live addresses); [I] inferred.

**Shader formulas (released 2026-10-08).** Items H-1..H-11 at the end, tagged [M], come from the compiled shaders.
- **Source:** the cache was unpacked with a local Oodle decoder ported from GPLv3 ooz, documented in
  notes/car-paint.md. The user approved it on 2026-10-08.
- **Local only:** the decoder and the unpacked cache stay git-ignored and never ship. The client takes these results
  only as values and formulas.
- **Evidence** (local): out/bsim/agents/AV1/notes.txt, out/bsim/agents/AV0/notes.txt (cage_shaders.txt,
  hexglass_shaders.txt) and out/bsim/agents/AV1/sc*/.
- **Team constants:** the cbuffer start register differs per shader (36 for grass, panels and frames; 37 for the cage,
  NetFence and generator). AV1 resolved it from each record's bindings: every arena surface uses the team **primary**
  and FB(primary); the crowd also uses the secondary.

**Sub-agent files and local assets** (git-ignored, game-derived; never ship):
- out/bsim/assets_local/arena/textures/: 37 PNGs plus stats.json (format, sRGB flag, address mode);
- out/bsim/assets_local/arena/meshes/: 37 world-space OBJs (every placed instance, uv0, one group per
  mesh/instance/section/material);
- out/bsim/agents/AV1/view/: plan, elevation and texture renders;
- AV1's placements, MICs and static switches: out/bsim/agents/AV1/stadium_*.tsv/txt.

## Shader formulas [M]
Notation:
- P_team = the team primary; t = sat(Y/256 + 0.5) blends team 0 → team 1 across midfield; sat = clamp 0..1;
- lum(c) = 0.3R + 0.59G + 0.11B; cosθ = the view angle's cosine against the surface normal;
- colours are linear.
