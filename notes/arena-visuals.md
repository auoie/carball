## Shader formulas [M]
**Lighting of the lit floor and frame pieces (corrected 2026-10-09 by LMP; supersedes the earlier "Phong + Σlights" paragraph):**
- **Baked only:** SceneColor = Emissive + Diffuse·L_baked(n).
- **The sun** (DirectionalLight__LC_1) is a static DirectionalLightComponent baked into the lightmaps (its guid is in every floor/frame lightmap); spot and point lights are baked too.
- **No shadow maps:** Stadium_P has no shadow-map data, so the DistanceFieldShadowed policy isn't used here.
- **No ambient or sky term:** the floor components are on the Static lighting channel only, and the sky light is on Dynamic/CompositeDynamic. AmbientColorAndSkyFactor is (0, 0, 0, 1) in the game view.
- **Car shadows** on the floor come from a separate modulated-shadow pass (ModShadowColor ≈ 0.425) [I].
- **Directional lightmap:** L = C0·Σ_i C1_i·sat(n_ts·B_i)², with B0 = (0, .8165, .5774), B1 = (−.7071, −.4082, .5774), B2 = (.7071, −.4082, .5774). C0 = NormalizedAverageColor, C1 = DirectionalMaxComponent × ScaleVector (sRGB DXT1, decoded); uvLM = UV1·CoordinateScale + CoordinateBias. For a flat normal L = C0·(C1.r + C1.g + C1.b)/3. 1-D vertex lightmaps use the same combine.
- **Mean linear L for a flat up-facing normal** (area-weighted; profiles and per-bin RGB local in out/bsim/agents/LMP/lm_stats.json):
  - Hex panels (Field_STD_Floor_Hex): side strips 0.764, 0.703, 0.540; the rest 1.096, 0.997, 0.752.
